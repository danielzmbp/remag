QUICK START
================================================================================

1. Create conda environment:
   conda env create -f environment.yml
   conda activate hyenadna-predictor

2. Run prediction:
   python predict_eukaryotes.py \
     --input contigs.fasta \
     --output-fasta eukaryotes.fasta \
     --output-table predictions.tsv

3. Or run the test example:
   ./test_example.sh

================================================================================
COMMAND-LINE OPTIONS
================================================================================

Required:
  --input FASTA              Input file with sequences
  --output-fasta FILE        Output file for eukaryotic sequences
  --output-table FILE        Output table with predictions

Optional:
  --model FILE               Path to pytorch_model.bin (default: ./pytorch_model.bin)
  --threshold FLOAT          Confidence threshold 0.0-1.0 (default: 0.5)
  --min-length INT           Minimum contig length bp (default: 1024)
  --device {auto,cpu,cuda,mps}  Device to use (default: auto)
  --batch-size INT           Batch size (default: 64)

Examples:
  # Conservative filtering (high confidence)
  python predict_eukaryotes.py --input in.fasta --output-fasta out.fasta \
    --output-table pred.tsv --threshold 0.9

  # CPU-only mode
  python predict_eukaryotes.py --input in.fasta --output-fasta out.fasta \
    --output-table pred.tsv --device cpu

  # Process smaller contigs
  python predict_eukaryotes.py --input in.fasta --output-fasta out.fasta \
    --output-table pred.tsv --min-length 500

================================================================================
TECHNICAL DETAILS
================================================================================

Prediction algorithm:
  1. Splits contigs into 1024bp windows with 50% overlap
  2. Runs inference on each window batch
  3. Uses majority voting across windows
  4. Returns confidence as proportion supporting prediction
  5. Filters by confidence threshold (default: 0.5)

Adaptive stride optimization:
  • Contigs < 2kb:    512bp stride (50% overlap)
  • Contigs 2-10kb:   2048bp stride (2x window)
  • Contigs > 10kb:   8192bp stride (8x window)
  • Early stopping: activates at 90% confidence

This provides 5-10x speedup on large contigs while maintaining accuracy.

================================================================================
TROUBLESHOOTING
================================================================================

Model not found:
  → Ensure pytorch_model.bin is in the same directory as script

Out of memory:
  → Reduce --batch-size (try 32 or 16)
  → Use --device cpu
  → Process data in smaller batches

Slow prediction:
  → Use --device cuda for NVIDIA GPUs
  → Use --device mps for Apple Silicon (M1/M2)
  → Increase --batch-size if GPU memory available
